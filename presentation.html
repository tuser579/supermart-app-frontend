Backend & Security

Backend API Integration & Security

Strict authentication flow connecting client directly to enterprise backend endpoints.

🔒 Real Database Authentication
  • ✓ Direct validation against REST API at supermart-api.up.railway.app
  • ✓ Elimination of fake/demo user fallback creation
  • ✓ Password complexity enforcement (Min 8 chars, 1 uppercase, 1 special char)
  • ✓ Real-time error messages returned from server validation
🔑 Token Lifecycle & Route Guards
  • ✓ Dual token strategy: Short-lived Access Token + Long-lived Refresh Token
  • ✓ Automatic HTTP 401 response interceptor with silent token refresh
  • ✓ Navigation route guards in root layout preventing unauthorized access
  • ✓ Automatic role-based redirection on reload or authentication
